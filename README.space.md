# Folio: live demo

Ask questions about documents and get cited, fact-checked answers. This Space runs
Folio in demo mode on sample documents: Al-Nahiyan Khushbu's public CV,
publications, research, projects and blog. You can also upload up to 3 files of
your own (5 MB each); they stay private to your browser session and are deleted
after an hour of inactivity.

- Portfolio: https://docalnahiyan.github.io
- Source code: https://github.com/docAlnahiyan/folio

This Space is deployed automatically from the GitHub repository; edit the code
there, not here.
